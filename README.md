# 🎮 **Simon Game - A Classic Memory Challenge**

## **Overview**
The **Simon Game** is a modern recreation of the popular electronic memory game from the 1970s and 1980s. The game consists of a sequence of tones and lights that the player must repeat. As the game progresses, the sequence becomes progressively longer and more complex. The game ends when the player fails to correctly replicate the sequence.

## **Features**
- 🟢 **Interactive Gameplay**: The game provides a sequence of lights and sounds that the player must remember and repeat.
- 🔊 **Audio-Visual Feedback**: Each button press is accompanied by a corresponding sound and color.
- 🔄 **Progressive Difficulty**: The game increases in difficulty as the player progresses.
- 🎯 **Score Tracking**: Players can challenge themselves to reach a new high score.
- 🎨 **Simple & Intuitive UI**: Designed for an engaging and user-friendly experience.
- 🖥️ **Cross-Platform Compatibility**: Can be played on desktop and mobile browsers.

## **Technologies Used**
- **JavaScript** for game logic  
- **HTML5 & CSS3** for UI design  
- **jQuery** for event handling and animations  
- **Audio API** for sound effects

How to Play
Press Start: The game will display a sequence of colors and sounds.
Repeat the Sequence: Click the buttons in the correct order.
Increase the Challenge: Each round adds a new step to the sequence.
Win or Lose: If you press the wrong button, the game ends.
Try Again: Restart and challenge yourself to beat your previous score!
